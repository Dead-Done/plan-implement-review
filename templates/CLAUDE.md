# Project context

This project keeps its shared state in an Obsidian vault at `vault/`.

- **Before starting any work:** read `vault/Status.md` and the last ~20 lines of `vault/Log.md`.
- **While working:** keep `vault/Status.md` current (Doing / Todo / Done / Decisions) and append a line to `vault/Log.md` for each meaningful step: `- YYYY-MM-DD HH:MM [agent] what happened`.
- **For substantial changes:** use the `/plan-implement-review` skill (Opus plans, Sonnet implements, Opus reviews). See `vault/README.md`.
