# Agent instructions

Shared project state lives in the Obsidian vault at `vault/`.

1. Before starting, read `vault/Status.md` (Doing / Todo / Done / Decisions) and the tail of `vault/Log.md`.
2. Don't start work that's already listed under Doing by another agent without checking with the user.
3. When you start a task, add it under Doing. When you finish, move it to Done and add any follow-ups to Todo.
4. Append one line per meaningful step to `vault/Log.md`: `- YYYY-MM-DD HH:MM [your-agent-name] what happened`. Never edit other agents' lines.
5. Plans live in `vault/Plans/`, reviews in `vault/Reviews/`. See `vault/README.md`.
